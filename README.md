# Education OS Spatial Presenter

First-person spatial presentation engine based on Memory Palace learning.

Core principles:

- First-person exploration, not slide-by-slide presentation
- World = long-term spatial memory
- Once a world is used for learning, its spatial layout should not casually change
- Knowledge and world assets are separated
- Student Guide and Teacher Guide are separate layers
- World images are stored locally on each device
- Wireless iPad presentation is the primary classroom target
- Wired display is a fallback
